# Imagens das plantas

Coloque aqui **uma imagem por planta**, usando exatamente o nome de arquivo declarado no campo `imagem` de cada entrada em `src/data/plants.json`.

## Dicas

- Use `.webp` para arquivos pequenos (tamanho alvo: 200–400 KB).
- Proporção recomendada: **4:3 ou 16:9** (o card renderiza num quadro de altura fixa `h-48` com `object-cover`).
- Se quiser usar `.jpg` ou `.png`, troque a extensão no campo `imagem` de cada entrada em `plants.json`.
- Até você adicionar as fotos, o card mostra um ícone de folha como placeholder — o app funciona normalmente sem imagens.
